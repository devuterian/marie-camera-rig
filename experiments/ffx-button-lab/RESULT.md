# Prototype result

이번 실험의 결과는 아래 구조야.

```text
FFX pseudo effect
├─ 기본 이동
├─ 타깃과 초점
├─ 자동 움직임
├─ 렌즈
└─ 빠른 실행
   ├─ ⚡ 충격 추가
   ├─ ↺ 값 초기화
   ├─ ● Bake 요청
   └─ ✕ 리그 지우기
```

`빠른 실행` 항목은 `CANNOT_TIME_VARY` 체크박스다. 패널이 열려 있을 때 `app.scheduleTask()`가 0.3초마다 확인하고, 체크되면 해당 JSX 작업을 실행한 뒤 값을 0으로 돌린다.

최종 제품에서는 짧고 되돌리기 쉬운 `충격 추가`, `값 초기화`만 Effect Controls 빠른 실행에 남기고, 실제 Bake와 제거는 패널의 진짜 버튼을 기본 경로로 두는 것이 안전하다.
